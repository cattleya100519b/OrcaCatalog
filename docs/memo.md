# 徒然

- ユーザが適切な画像を投稿するとは限らなくて、要は人がそれを確認する前に、認識モデルに確度を出してもらった上で、人が確認の介入をするかどうか、みたいなのも考慮する羽目になるかと。  
  性悪説だが、実際に問題になるかと。（**AIが候補を出して、人間の確認コストを減らす**）
  - 間違えて別個体を選ぶ
  - 写真がそもそもシャチではない
  - 同じ写真を何度も投稿する
  - 個体識別に必要な部位が写っていない
  - GPSが間違っている
  - 撮影日時がおかしい
  - AIが別個体と判定する
  - 人間の専門家でも判断が難しい
```
Human-in-the-loop

ユーザー投稿
    ↓
入力チェック
    ↓
AIによる判定・スコアリング
    ↓
┌──────────────┐
│ 確度が高い       │ → 自動承認候補
│ 確度が低い       │ → 人間確認
│ 明らかに不適切   │ → 却下候補
└──────────────┘
    ↓
データベース
```
```
Photo
 ↓
AI identification
 ↓
candidate individual
 ↓
confidence
 ↓
human review
 ↓
confirmed identification
```
