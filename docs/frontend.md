# Frontend

## Next.js, ReactNative, Flutter で試作した所感
- フロント側で変更が生じた時に、web と native でそれぞれ UI を考えて変更する必要があって、  
  それを nextjs / reactnative と分けて実装するか、flutter 一箇所で変更するかなんだけど、  
  その 2つのフロントの変更を一つのコード内で反映させるのが結構煩雑さを感じた。
  > WebとNativeのUI変更を1か所で済ませられる  
  > 1か所のコードで、性質の違う2つのUIを表現しなければならない  
  > 「コードを共有すること」と「開発コストを減らすこと」は別
